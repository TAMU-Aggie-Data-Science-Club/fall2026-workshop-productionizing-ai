# Nimbus workshop -- fully pinned dependencies.
#
# Single source of truth for setup: the devcontainer, `make setup` and CI all
# install from here, so the two setup paths cannot drift.
#
# EVERY package is pinned, including transitive ones. Pinning only the direct
# dependencies does not protect you: a workshop breaks just as thoroughly when
# a library four levels down ships a new minor release the night before.
#
# torch comes from PyTorch's CPU-only index. On Linux the default PyPI wheel
# bundles CUDA (~2.5 GB), which would make the Codespaces image build unusable
# on a 2-core machine that will never see a GPU. Verified present for
# cp311 manylinux_2_28_x86_64 (Codespaces) and macOS arm64 (local).
--index-url https://download.pytorch.org/whl/cpu
--extra-index-url https://pypi.org/simple
